# Java OOPS Practice

This repository contains my Java practice programs for Object-Oriented Programming (OOP) concepts.

## Concepts Covered

### 1. Classes and Objects
- Creating objects from a class
- Accessing and displaying object attributes

### 2. Inheritance
- Creating child classes using `extends`
- Reusing properties and methods from the parent class

### 3. Polymorphism
- Method overriding
- Runtime polymorphism using parent class references

### 4. Encapsulation
- Using private variables
- Accessing data through getter and setter methods

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
